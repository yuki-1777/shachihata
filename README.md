# 聲印 (Sei-in)

声で外径が決まる印鑑のデザインコンセプト & プロトタイプ。

> 印鑑は「個人の識別」のために存在する。しかし苗字だけでは個人を特定しきれない時代になった。そこで、もう一つの個人を表す身体的特徴である **声** を、印鑑の外径として刻み込む。
> 中央の文字（名前）は社会的なアイデンティティ、外径の凹凸は身体的なアイデンティティ。両者を組み合わせて、その人だけの印影を成立させる。

声を録音 → 波形を解析 → 円の外径に反映 → SVG 出力 → 3D モデリング → プロトタイプ印鑑、というワークフローを想定したツール群。

## v2 の機能

### 録音
- 名前を1〜5文字のひらがなで入力 → 文字ごとに録音スロット生成
- 押している間だけ録音（マウス長押し / `1`〜`5` キー）
- 文字ごとに自動トリミング（無音除去）＋手動範囲調整可

### 形状生成
- 文字数で円を等分（4文字=4等分、5文字=5等分、12時開始の時計回り）
- 各セクタ内に対応する音の波形を配置
- **量子化**：振幅を基準線にスナップして単純化
  - モード A：0クロスで区切った山ごとに1スナップ
  - モード B：方向転換ごとにスナップ
- **接続方法**：階段 / 線形 / 滑らか
- **基準線**：等間隔 or 対数間隔、本数調整可
- **正規化**：文字ごと（推奨）or 全体

### 確認・調整
- 直線ビュー / 円ビュー切替
- 各文字の波形を拡大表示モーダルで確認
  - ホイールズーム、ドラッグパン
  - 再生（Space で停止/再生）＋カーソル追従
  - エンベロープ・推定母音区間・量子化結果の重ね表示
  - トリミング範囲のドラッグ調整

### 出力
- SVG ダウンロード（Blender / Fusion 等での 3D モデリング素材として）

## 起動方法

`getUserMedia` がローカル HTML（`file://`）から使えないため、HTTP サーバが必要：

```bash
python3 -m http.server 8000
# → http://localhost:8000/voice_seal_v2.html
```

または `npx serve .` など任意の静的サーバ。
