聲印 プロジェクト

声を印鑑のかたちに変換する研究と、その途上で生まれた音声処理学習ツール群

目的：人の声を音響的に分析し、その特徴（フォルマント・ピッチ・声道形状など）を印鑑の輪郭に反映させる。
最終的には「自分の声で作る印鑑」になることを目指している。各ツールはその過程で検討した方向性や、学習用に作った可視化ツール。
メインツール
本命

聲印 v2 — 形状生成ツール

名前を録音すると、各文字の波形・スペクトル特徴を印鑑の輪郭に変換するメインツール。3帯域モード（低・中・高域を3本の同心円に）、1周期モード（自己相関で抽出した1周期をパターン化）、量子化、対数間隔基準線などを搭載。

機能 録音 / 波形分析 / SVGエクスポート / 3表示モード
 v3

聲印 v3 — 多モード版（FFT10点・MFCC・音素ほか）

v2を発展させた版。形状モードに「FFT10点（音素ごとに対数間隔10点をサンプリングして花びら状の形を生成）」「MFCC」「音素軌跡」「フォルマント」「STFT」など多数を搭載。複数録音の品質マーク＋平均化対応、印影文字（縦書き朱色）の埋め込みも可能。

機能 録音 / 多モード形状 / 複数録音平均 / SVG＋文字エクスポート
学習・実験ツール
教育

声の分析ラボ

録音した声を「波形・スペクトル・スペクトログラム」の3視点で観察。F0、F1、F2、スペクトル重心、ZCR、推定母音などの特徴量をリアルタイム表示。各専門用語に中学生向け解説モーダル付き。1本線プレビューで「印鑑の輪郭に何を使うか」を試せる。

機能 録音 / 合成母音 / 3視点ビュー / 特徴量表示 / 解説
 教育

MFCC を見てみよう

音声認識・話者認識で標準的に使われる「MFCC（メル周波数ケプストラム係数）」が、録音波形からどう計算されるかを9ステップで可視化。波形 → 窓掛け → FFT → メルフィルタ → log → DCT の各段の入力と出力をビジュアルで追える。

機能 録音 / 合成母音 / 9ステップ可視化 / 各段の説明
 設計

パターン生成ラボ

「子音の音響的性質（点の数・高さ・鋭さ）から自動で形が決まる」ジェネラティブな50音パターン生成ツール。子音セクション幅、子音高さ、母音振幅、線太さなどをスライダーで調整して全パターンに即時反映。直線/円表示切替あり。

機能 50音パターン / ルールベース生成 / リアルタイム調整
 本命候補

声紋パターン合成

「ルールベースの基本パターン × 録音した声のMFCC変調」のハイブリッド方式。文字ごとに録音すると、子音/母音境界を自動検出してそれぞれのMFCCを計算し、基本パターンに「その人の声色」を変調として加える。変調ON/OFF切替で純粋なルール版と比較可能。

機能 録音 / 子音母音分離 / MFCC変調 / ハイブリッド合成
 実験

メル帯域合算ラボ

声をメルスペクトログラムに分解し、好きな帯域をクリックでON/OFFして時間方向に足し算 → 1本の輪郭線にマッピングする実験ツール。「低域だけ」「子音帯域だけ」など組み合わせを試して印鑑形の質感を探る。

機能 メル分解 / 帯域選択 / 合算 / 円マッピング
